# Unix OS from Scratch

*A Bare-Metal x86-64 Kernel Built From Nothing*

Every program in this author's other books -- a CUDA kernel, a tensor compiler, a C++ inference server -- ran *on top of* an operating system, and quietly relied on it for almost everything: memory that just appears when you ask, a filesystem, the ability to print a character to a screen. This book builds the thing underneath all of that. It starts at the one moment none of those other books ever had to think about -- the instant a CPU has power and literally nothing else exists yet, not even a guarantee that memory has been zeroed -- and builds forward from there: booting a real kernel with a real bootloader, talking to real hardware one device at a time, giving processes real memory isolation, and eventually a filesystem and a shell a person could actually type into.

This book is independent: it does not assume or reference any other book in this author's series, and it builds everything from Chapter 1 rather than pointing elsewhere for it. What it keeps is the same discipline its sibling books follow: every piece of code in this book is genuinely assembled and compiled for a real target, and wherever a real answer does not require hardware this book's own authoring environment does not have, it is genuinely run and checked -- in this book's case, genuinely *booted*, in a real, complete hardware emulator (QEMU), with real captured output locked into the page rather than a screenshot or an invented number. Getting Started explains exactly where this book's own real hardware/toolchain limits fall.

## How to read this book

Every chapter follows the same shape: an intuition built from a concrete picture before any code, a background section with the real, complete implementation, one or more worked examples with genuinely produced output, a `[COMMON TRAP]` callout naming a specific, real mistake this book's own authoring process actually hit rather than a vague warning, a chapter summary, self-check questions, and worked answers. Code that can genuinely build and boot in this book's own authoring environment is genuinely built and booted, and its exact output locked into the page. This book's own table of contents grows one chapter at a time rather than being fixed in advance -- see `TABLE_OF_CONTENTS.md` in this book's own repository for its current, honest state.
